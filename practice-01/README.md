## Задание 1
Один файл запускается и в Node.js, и в браузере. В браузере `typeof document` равен `object`, потому что DOM предоставляется браузером. В Node.js `document` отсутствует, поэтому результат — `undefined`.

## Задание 2
| Выражение | Фактический результат | Тип |
|---|---|---|
| `"8" + 2` | `"82"` | string |
| `"8" - 2` | `6` | number |
| `Number("8") + 2` | `10` | number |
| `"12" > "3"` | `false` | boolean |
| `12 === "12"` | `false` | boolean |
| `Number("")` | `0` | number |
| `Number("text")` | `NaN` | number |
| `Boolean("false")` | `true` | boolean |
| `typeof null` | `"object"` | string |
| `typeof NaN` | `"number"` | string |

Причина основных различий: `+` при наличии строки выполняет конкатенацию, `-` преобразует операнды в числа; сравнение строк выполняется лексикографически; непустая строка истинна при Boolean; `typeof null` исторически возвращает `"object"`.

## Задание 4
Для варианта 1: `12`, `5`, `3`.

```text

День 3: выполнено 1, осталось 0

```

Цикл `while` останавливается после обнуления остатка.

## Задание 5. Отладка
Исходная ошибка: строки складывались как текст, поэтому `"3" + "2"` давало `"32"`. Исправление выполнено явным преобразованием через `Number()`.

Вторая ошибка: цикл использовал условие `< 4`, поэтому суммировал только `1 + 2 + 3`. Исправление: `<= 4`.

После исправления:
```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```
