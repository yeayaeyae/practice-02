## Выполненные задания

### 1. Проверка запуска JavaScript

Создан файл `js/hello.js`, содержащий простую программу на JavaScript.

Запуск выполняется через Node.js:

```powershell
node js/hello.js
```

Программа успешно запускается и выводит результат в консоль.

### 2. Работа с типами данных

В файле `js/types.js` рассмотрены основные типы данных JavaScript:

* `number`;
* `string`;
* `boolean`;
* `null`;
* `undefined`.

Также выполнена проверка типов с использованием `typeof`.

Запуск:

```powershell
node js/types.js
```

### 3. Расчёт прогресса

В файле `js/progress.js` реализован расчёт прогресса выполнения задач.

Для варианта 1 использованы следующие исходные данные:

* общее количество задач — **12**;
* выполнено задач — **5**;
* дневной лимит — **3**.

На основании этих данных программа рассчитывает процент выполнения и оставшееся количество задач.

Запуск:

```powershell
node js/progress.js
```

### 4. Расчёт учебного плана

В файле `js/plan.js` выполнен расчёт параметров учебного плана с использованием условий и арифметических операций.

Запуск:

```powershell
node js/plan.js
```

### 5. Отладка программы

В файле `js/debug.js` рассмотрена работа с ошибками JavaScript и инструментами разработчика браузера.

Были проверены:

* сообщения об ошибках;
* значения переменных;
* пошаговое выполнение программы;
* точки останова.

Для запуска необходим Node.js.

Из папки `practice-01` выполнить:

```powershell
node js/hello.js
node js/types.js
node js/progress.js
node js/plan.js
node js/debug.js
```

Файл `index.html` можно открыть непосредственно в браузере.
