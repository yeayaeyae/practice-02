## Задание 1
Проведены шесть экспериментов с функциями, ссылками, spread и параметрами по умолчанию. В эксперименте со стрелочной функцией исправлен пропущенный `return`, поэтому `square(4)` возвращает число `16`.

Ключевые наблюдения:
- функция `sum` не преобразует строки автоматически;
- объект, присвоенный другой переменной, остаётся тем же объектом;
- spread массива создаёт новый массив, но вложенные объекты сохраняют ссылки;
- spread объекта создаёт новый верхний объект;
- значение по умолчанию используется для пропущенного аргумента и `undefined`, но не для `null` или `""`.

## Задание 2
Реализована `createTask`: проверяются положительный безопасный целочисленный `id`, строковое название длиной 1–100 после `trim()`, приоритет `low/medium/high`. Новая задача всегда создаётся с `completed: false`.

## Задание 3
Реализованы `findTaskById`, `getPendingTasks`, `getTaskTitles`, `getTaskStats` с `find`, `filter`, `map` и расчётом сводки.

Для общего набора:
`{ total: 4, completed: 2, pending: 2, progress: 50 }`.

## Задание 4
Реализованы добавление, изменение статуса, переименование и удаление без мутации исходного массива. Использованы spread, `map` и `filter`.

## Задание 5
`main.js` выполняет общий сценарий: добавление id=20, выполнение id=4, переименование id=10, удаление id=7, отказ повторного добавления id=20 и проверку сохранности `demoTasks`.
