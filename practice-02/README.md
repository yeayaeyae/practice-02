## Выполненные задания

### 1. Модель данных

В файле `src/data.js` создан набор тестовых задач.

Для варианта 1 используются идентификаторы задач:

```text
11, 23, 37, 41, 58, 64
```

Каждая задача содержит основные свойства:

* идентификатор;
* название;
* приоритет;
* статус выполнения.

### 2. Создание задач

В `src/task-service.js` реализована функция:

```javascript
createTask()
```

Функция создаёт новую задачу и устанавливает значение приоритета `medium`, если оно не передано явно.

Также выполняется проверка входных данных.

### 3. Поиск задачи

Реализована функция:

```javascript
findTaskById()
```

Она выполняет поиск задачи по идентификатору.

### 4. Получение невыполненных задач

Реализована функция:

```javascript
getPendingTasks()
```

Функция возвращает отдельный массив невыполненных задач, не изменяя исходный массив данных.

### 5. Получение названий задач

Реализована функция:

```javascript
getTaskTitles()
```

Она преобразует массив объектов задач в массив их названий.

### 6. Получение статистики

Реализована функция:

```javascript
getTaskStats()
```

Она формирует сводную статистику по задачам.

Также предусмотрена корректная работа функции с пустым массивом.

### 7. Дополнительные операции

В сервисе реализованы операции:

* добавление задачи;
* изменение статуса выполнения;
* переименование задачи;
* удаление задачи.

## Запуск

Необходимо установить Node.js.

Из папки `practice-02` выполнить:

```powershell
node checks.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```
