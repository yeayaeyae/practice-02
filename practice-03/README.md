## Цель работы

Изучить работу с DOM, обработку событий и взаимодействие JavaScript с HTML-элементами.

## Задания

В работе реализованы:

- создание и отображение списка задач;
- добавление новых задач;
- изменение статуса выполнения задачи;
- удаление задач;
- фильтрация задач;
- обработка событий через делегирование;
- использование data-* атрибутов;
- разделение логики приложения на модули.

## Вариант

Вариант 1.

Идентификаторы задач: 11, 23, 37, 41, 58, 64.

## Структура проекта

- index.html — основная страница приложения;
- checks.html — страница проверки;
- checks.js — автоматические проверки;
- src/ — исходный JavaScript-код приложения.

## Запуск

Для проверки JavaScript-кода выполните:

node checks.js

Также можно выполнить:

npm.cmd run check

Для проверки интерфейса необходимо открыть index.html в браузере.

## Результат

Создано интерактивное приложение для работы со списком задач. Реализованы добавление, удаление, изменение статуса и фильтрация задач.

## Вывод

В ходе практической работы были изучены основные принципы работы JavaScript с DOM и событиями. Получены навыки создания интерактивного интерфейса и организации клиентского JavaScript-кода.
