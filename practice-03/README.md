## Выполненные задания

### 1. Отображение списка задач

В файле `index.html` создан интерфейс для отображения списка задач.

Данные задач хранятся отдельно от представления и передаются в функции формирования интерфейса.

Для варианта 1 используются идентификаторы:

```text
11, 23, 37, 41, 58, 64
```

### 2. Работа с DOM

В проекте реализована генерация элементов списка задач средствами JavaScript.

Используются методы DOM для:

* поиска элементов;
* создания элементов;
* изменения содержимого;
* добавления элементов на страницу;
* удаления элементов.

### 3. Фильтрация задач

Добавлены фильтры списка задач:

* все задачи;
* выполненные;
* невыполненные.

При изменении фильтра список обновляется без перезагрузки страницы.

### 4. Изменение статуса

Для задачи предусмотрено изменение состояния выполнения.

Пользователь может переключать статус задачи, после чего интерфейс обновляется.

### 5. Удаление задачи

Для каждой задачи предусмотрено действие удаления.

Удаление выполняется через обработчик события и обновляет отображаемый список.

### 6. Делегирование событий

Для обработки действий списка используется делегирование событий.

Вместо создания отдельного обработчика для каждого элемента используется общий обработчик контейнера списка.

Для определения нажатого элемента используются атрибуты `data-*`.

### 7. Разделение логики

Логика проекта разделена на несколько модулей:

* `task-service.js` — операции с данными;
* `task-selectors.js` — выбор и фильтрация задач;
* `task-view.js` — формирование DOM;
* `main.js` — связывание данных, интерфейса и событий.

## Запуск

Для просмотра интерфейса необходимо открыть:

```text
index.html
```

в браузере.

Автоматические проверки можно запустить из папки `practice-03`:

```powershell
node checks.js
```

Интерактивные проверки DOM также доступны через:

```text
checks.html
```
